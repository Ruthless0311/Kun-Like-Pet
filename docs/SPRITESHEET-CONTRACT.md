# Kun Like 桌宠 · 精灵图契约

素材完全沿用 Codex 桌宠（`~/.codex/pets/`）的固定图集契约，未做任何重新设计。

## 图集规格

| 项目 | 值 |
| --- | --- |
| 文件 | `assets/spritesheet.webp` |
| 格式 | WebP（支持 PNG） |
| 尺寸 | `1536 × 1872` px |
| 网格 | **8 列 × 9 行** |
| 单格 | `192 × 208` px |
| 背景 | 全透明 |
| 未用格 | 必须全透明 |

> 契约来源：Codex 桌宠官方契约（`hatch-pet` 技能参考文档）。
> 画布上**不要**添加标签、留白边、网格线、格内阴影或额外帧，动画靠 CSS
> `background-position` 按固定行列取帧。

## 动画行

| 行 | 状态 | 使用列 | 帧时长（ms） |
| --- | --- | ---: | --- |
| 0 | idle（待机呼吸） | 0–5 | 280, 110, 110, 140, 140, 320 |
| 1 | running-right（向右跑） | 0–7 | 各 120，末帧 220 |
| 2 | running-left（向左跑） | 0–7 | 各 120，末帧 220 |
| 3 | waving（挥手） | 0–3 | 各 140，末帧 280 |
| 4 | jumping（跳跃） | 0–4 | 各 140，末帧 280 |
| 5 | failed（出错低落） | 0–7 | 各 140，末帧 240 |
| 6 | waiting（等待回复） | 0–5 | 各 150，末帧 260 |
| 7 | running（专注干活） | 0–5 | 各 120，末帧 220 |
| 8 | review（思考审阅） | 0–5 | 各 150，末帧 280 |

## 行用途约定

- `idle`：平静的低干扰呼吸/眨眼循环，可作为降动效模式的首帧。
- `running-right` / `running-left`：左右方向移动，帧序与方向语义须保持。
- `waving`：打招呼/引起注意；起手、举起、收回三段式。
- `jumping`：预备、起跳、腾空、下落、站稳。
- `failed`：出错/失落反应，可读但不过度花哨。
- `waiting`：等待用户输入（审批、提问），期待的询问姿态。
- `running`：主动工作状态（专注处理/思考/敲键盘），**不是**跑步动作。
- `review`：审查/思考循环。

## 状态机 → 动画映射

本插件宿主端状态机输出 `mode`，客户端映射到图集行：

| mode | 动画行 | 气泡文案 |
| --- | --- | --- |
| `idle` | 0 idle | 休息中~ 有事叫我 |
| `working` | 7 running | 努力工作中… |
| `review` | 8 review | 思考中… |
| `waiting` | 6 waiting | 在等你回复哦~ |
| `failed` | 5 failed | 呜…出错了 (._.) |
| `celebrating` | 3 wave / 4 jump（交替） | 完成啦！你干嘛~哎哟 |
| 拖动 | 1/2 run（方向跟随） | 呜哇~ 别拽我！ |
| 点击 | 3 wave（2.4s 反应） | 诶嘿~ |
